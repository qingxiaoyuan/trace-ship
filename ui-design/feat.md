# 前端系统需求文档

需要开发一个「TraceShip - 软件版本发布管理与提交规范审查系统」的前端界面。系统用于支撑发布工程师、开发人员、测试人员、项目管理员、系统管理员对软件版本发布流程进行规范化管理。

前端部分负责提供统一的用户界面，覆盖项目接入、凭证管理、仓库管理、提交规范审查、Tag 生成与发布、Jenkins 构建、工作流审批、发布看板、系统管理等核心场景。

## 本次需求

开发一个基于 Web 的前端管理系统，用于实现以下功能。

### 用户登录与域账号接入

提供独立的登录入口，支持不同来源账号登录系统。

1. 支持域账号（LDAP/AD）登录，默认选中域账号 Tab。
2. 支持本地应急账号登录切换。
3. 登录页展示系统 Logo、名称、版本号。
4. 用户名、密码输入框支持非空校验。
5. 登录按钮具备 Loading 态，失败时保留用户名并显示错误提示。
6. 登录成功跳转工作台仪表盘。

### 工作台

为不同角色提供统一的入口页面，展示核心指标、待办事项与快捷操作。

1. 展示近 7 天发布数、待审批数、构建成功/失败数、Commit 合规率等 KPI 卡片。
2. 展示最近发布记录列表，支持查看详情。
3. 展示当前用户待审批任务，支持一键跳转审批。
4. 展示非法提交预警数量，支持跳转预警页。
5. 提供「新建发布」快捷入口。

### 项目管理

对系统项目进行全生命周期管理，支持项目 CRUD、成员管理、规则配置、外站绑定。

1. 项目列表支持搜索、筛选、新增、编辑、停用/启用、删除。
2. 项目详情页通过 Tab 切换展示基本信息、仓库、成员、审批流、发布记录、规则配置、外站绑定。
3. 项目成员支持添加、移除、修改角色。
4. 外站绑定支持关联 Git 仓库、Jenkins 任务、SVN 仓库，并指定凭证与凭证归属。
5. 规则配置支持版本号规则、发布周期、正式发布分支限制、测试版本命名前缀、Commit 合规率阈值。

### 仓库管理

按项目接入 Git（GitLab/Gitea）/ SVN 仓库，配置凭证、默认分支，测试连通性。

1. 仓库列表支持按项目、仓库类型、健康状态筛选。
2. 仓库新增/编辑关联项目、平台、地址、默认分支、凭证及凭证归属。
3. 支持仓库连通性测试，展示成功或失败提示。
4. 支持同步提交操作入口。

### 凭证管理

统一管理 GitLab Token、Gitea Token、SVN、Jenkins、LDAP、AI Key 等凭证。

1. 凭证列表支持按类型、作用范围、状态、过期时间筛选。
2. 凭证新增/编辑支持名称、类型、认证模式、凭证内容、用户名、作用范围、关联项目、过期时间、备注。
3. 列表页凭证内容脱敏展示。
4. 支持查看凭证使用记录。
5. 临期/过期凭证高亮提示。

### 提交规范审查

查询、审查项目提交记录，识别不合规提交，支持 AI 辅助审查。

1. 提交记录查询支持按项目、仓库、分支、提交人、时间范围、规范状态筛选。
2. 列表展示 commit 哈希、作者、提交时间、分支、消息摘要、变更类型、合规状态。
3. 支持查看 commit 详情抽屉，展示原始 message、解析结果、AI 审查建议。
4. 支持手动标记合规状态。
5. 非法提交预警页展示待处理、已忽略、已整改统计，支持标记处理状态、导出清单。

### Tag 生成与发布

引导用户完成从选择分支、提取 commit 差异、编辑发布说明到提交发布申请的完整流程。

1. 三步步骤条：选择项目与分支 → 提取并编辑 commit 差异 → 生成发布说明并提交。
2. 选择项目、仓库、来源分支、起始 Tag、发布类型（正式/测试）。
3. 提取差异后展示 commit 列表，支持全选/取消全选、合并选中、排除选中、AI 辅助生成摘要。
4. 展示差异统计面板：总 commit 数、A 类更新、F 类更新、配置项改动、不合规提交。
5. 发布说明编辑器支持版本号、Tag 名称、Git 哈希、来源/目标分支、变更类型、更新内容、配置项改动、关联性改动、测试验证状态、AI 风险提示。
6. 支持保存草稿、提交审批、一键推 tag。
7. 正式/测试版本发布页分别展示对应的合规校验面板与特殊规则提示。

### Jenkins 构建

按项目维护 Jenkins 任务配置，查看构建状态与实时日志。

1. Jenkins 任务配置列表支持新增/编辑/删除/测试连接。
2. 任务配置字段包括关联项目、任务名称、Jenkins 地址、Job 名、凭证、参数模板。
3. 构建状态列表展示任务名、构建编号、版本号、状态、开始时间、耗时。
4. 构建状态支持颜色与动画区分（排队中/构建中/成功/失败/中止）。
5. 支持查看构建日志抽屉，自动滚动，支持刷新与跳转 Jenkins 完整日志。

### 工作流审批

按项目配置审批流程，处理当前用户的待办/已办任务。

1. 流程定义配置页支持列表管理与 LogicFlow 可视化流程设计。
2. 流程画布支持开始、审批、抄送、条件、结束节点，右侧属性面板编辑节点属性。
3. 审批节点属性包括节点名称、审批人类型、审批人值、审批模式、超时提醒、自动转交。
4. 我的待办展示审批标题、申请人、项目、提交时间、当前节点、剩余时间、审批操作。
5. 审批详情弹窗展示发布基本信息、发布说明预览、关联 commit、构建结果，支持通过/驳回/转交与填写意见。
6. 我的已办展示审批动作、意见、时间，支持查看详情。

### 发布信息检索看板

支持按多维度检索、筛选发布记录，查看发布详情与统计报表。

1. 发布看板支持按项目、版本号、发布时间范围、发布类型、发布人、状态筛选。
2. 列表展示版本号、项目、发布类型、来源分支、发布人、创建时间、状态、操作。
3. 发布记录详情页通过 Tab 切换展示发布说明、关联提交、构建产物、审批记录、操作日志。
4. 统计报表页展示发布趋势、项目对比、合规率趋势、变更类型分布图表，支持导出 Excel。

### 系统管理

管理系统用户、角色权限、系统配置、操作日志。

1. 用户管理支持同步 LDAP、新增本地用户、编辑角色、启用/停用、重置密码。
2. 角色权限支持定义角色及菜单/按钮/接口权限，树形选择配置。
3. 系统配置按分类展示：LDAP/AD、Jenkins、AI 服务、存储、通知、安全策略、公告/模板。
4. 操作日志支持按时间、用户、模块、操作类型、资源类型、结果筛选与导出。

### 个人中心

展示个人信息，支持修改密码与通知偏好。

1. 展示用户头像、姓名、角色、部门、联系方式。
2. 支持修改密码。
3. 支持配置通知偏好（邮件/企业微信/钉钉/飞书）。

## 页面具体显示细节

### 登录页

页面布局：
- 居中卡片，宽度 420px，垂直水平居中，背景为登录页渐变。
- 卡片内边距 32px，圆角 8px。

显示内容：
- 系统 Logo + 名称「TraceShip」+ 版本号。
- 登录方式切换 Tab：域账号 / 本地账号。
- 用户名输入框、密码输入框（支持显示/隐藏密码）。
- 记住我复选框、忘记密码链接。
- 登录按钮（全宽、主色、Loading 态）。
- 底部提示：首次登录将自动同步 LDAP 用户信息。

### 仪表盘

页面布局：
- 顶部 4 列 KPI 卡片。
- 下方两栏：左 2/3「最近发布」表格，右 1/3「我的待办」+「非法提交预警」。

显示内容：
- 近 7 天发布数 + 环比。
- 待审批数（点击跳转待办）。
- 构建成功/失败数。
- Commit 合规率进度条。
- 最近发布列表：版本号、项目、类型、状态、时间。
- 我的待办：审批标题、申请人、提交时间、去审批按钮。
- 非法提交预警：待处理数量、查看按钮。

### 项目列表页

页面布局：
- 页面标题 + 新增项目按钮。
- 筛选栏 + 项目表格。

显示内容：
- 项目编码、项目名称、负责人（头像+姓名）、关联仓库数、成员数、状态、创建时间。
- 操作列：编辑、配置成员、外站绑定、停用/启用、删除。
- 新增/编辑弹窗字段：项目编码、项目名称、项目负责人、描述、状态。

### 项目详情页

页面布局：
- 页面标题 + 返回按钮 + 编辑按钮 + 状态标签。
- Tab 切换：基本信息 / 仓库 / 成员 / 审批流 / 发布记录 / 规则配置 / 外站绑定。

显示内容：
- **基本信息**：项目编码、名称、负责人、描述、状态、创建时间。
- **仓库**：仓库名称、类型、默认分支、凭证归属、健康状态；操作：添加仓库、编辑、测试、同步提交。
- **成员**：成员头像+姓名、部门、角色、加入时间；操作：添加成员、修改角色、移除。
- **审批流**：流程名称、业务类型、版本、启用状态；操作：新增、编辑、停用/启用。
- **发布记录**：项目维度的发布记录列表。
- **规则配置**：版本号规则、发布周期、正式发布分支限制、测试版本命名前缀、Commit 合规率阈值。
- **外站绑定**：外站类型、资源、凭证、凭证归属；操作：新增绑定、编辑、解绑。

### 仓库列表页

页面布局：
- 筛选栏 + 仓库表格 + 新增仓库按钮。

显示内容：
- 仓库名称、仓库类型（GitLab/Gitea/SVN 标签）、关联项目、仓库地址（可点击新窗口打开）、默认分支、凭证归属、最近同步时间、健康状态。
- 操作列：编辑、测试连通性、同步提交、删除。
- 新增/编辑弹窗字段：关联项目、仓库平台、仓库名称、仓库地址、默认分支、凭证、凭证归属、指定用户、Webhook 配置、额外配置。

### 凭证列表页

页面布局：
- 筛选栏 + 凭证表格 + 新增凭证按钮。

显示内容：
- 凭证名称、凭证类型、认证模式、所属用户、作用范围、关联项目、过期时间、状态。
- 操作列：编辑、删除、查看使用记录。
- 新增/编辑弹窗字段：凭证名称、凭证类型、认证模式、凭证内容、用户名、作用范围、关联项目、过期时间、备注。
- 使用记录抽屉：使用时间、调用来源模块、调用结果、错误摘要。

### 提交记录查询页

页面布局：
- 筛选栏 + commit 表格 + 同步提交按钮。

显示内容：
- 筛选条件：项目、仓库、分支、提交人、时间范围、规范状态。
- 表格列：commit 哈希（前 8 位）、作者、提交时间、分支、消息摘要、变更类型、合规状态。
- 操作列：AI 审查、查看详情、手动标记。
- 提交详情抽屉：原始 commit message、解析结果 JSON、AI 审查建议卡片、审查状态。

### 非法提交预警页

页面布局：
- 预警统计卡片 + 预警列表。

显示内容：
- 统计卡片：待处理（橙色）、已确认忽略（灰色）、已整改（绿色）。
- 列表列：项目、commit 哈希、不合规原因、提交人、提交时间、处理状态。
- 操作列：标记已整改、忽略、发送提醒、导出 Excel/PDF。

### Tag 生成与发布页

页面布局：
- 三步步骤条 + 步骤面板。

显示内容：
- **步骤 1**：项目、仓库、来源分支、起始 Tag、发布类型。
- **步骤 2**：左侧 commit 列表（复选框、合规状态、操作），右侧差异统计面板（总 commit、A/F 类、配置项改动、不合规）、AI 风险提示。
- **步骤 3**：发布说明编辑器（版本号、Tag 名称、Git 哈希、分支、变更类型、更新内容、配置项改动、关联性改动、测试验证状态、发布人、AI 风险提示），右侧实时预览。

- 测试版本：项目、基础版本号、测试版本号（自动追加 -test.{n}）、来源分支、发布说明、产物路径隔离提示。
