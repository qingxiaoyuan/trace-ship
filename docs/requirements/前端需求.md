# 前端需求文档

## 一、系统定位

面向研发、测试、项目管理员、系统管理员等角色，提供软件版本发布全流程的可视化操作入口。覆盖项目接入、代码仓库管理、提交规范审查、TAG 生成与发布、Jenkins 打包触发、工作流审核、发布看板等能力。

---

## 二、功能模块

### 1. 用户登录与域账号接入

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-LOGIN-01 | 支持域账号（LDAP/AD）统一登录，登录后自动同步用户名、部门、邮箱等基础信息 | P0 |
| F-LOGIN-02 | 登录成功后根据域账号权限映射到系统角色（普通用户/项目管理员/超级管理员） | P0 |
| F-LOGIN-03 | 支持本地超级管理员账号应急登录，用于域账号服务不可用时维护系统 | P1 |
| F-LOGIN-04 | 登录页展示系统名称、版本号、登录方式切换（域账号/本地账号） | P1 |

### 2. 项目管理中心

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-PROJECT-01 | 项目列表：展示项目编码、名称、负责人、关联仓库数、创建时间、状态 | P0 |
| F-PROJECT-02 | 项目新增/编辑/停用：支持录入项目基础信息、配置版本号规则、发布周期规则 | P0 |
| F-PROJECT-03 | 项目详情：展示项目下接入的代码仓库、成员、审批流、历史发布记录 | P0 |
| F-PROJECT-04 | 项目成员管理：为项目添加/移除成员，分配项目角色（开发/测试/管理员/审核人） | P0 |
| F-PROJECT-05 | 发布规则配置：支持配置"正式版本三天一发"、测试版本命名规则、正式发布分支限制等 | P1 |
| F-PROJECT-06 | 项目外站绑定：为项目绑定 Git 仓库、Jenkins 任务、SVN 仓库，选择对应凭证 | P0 |
| F-PROJECT-07 | 项目外站绑定支持凭证归属选择：当前登录用户、指定用户、项目固定凭证、系统全局凭证 | P0 |

### 3. 代码仓库管理

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-REPO-01 | 支持按项目分项目接入 Git 仓库，平台类型可选 GitLab/Gitea，后期可扩展 | P0 |
| F-REPO-02 | 仓库配置支持选择已有凭证，或新增凭证（Token / 账号密码两种模式） | P0 |
| F-REPO-03 | 仓库配置支持选择凭证归属模式：当前登录用户、指定用户、项目固定凭证、系统全局凭证 | P0 |
| F-REPO-04 | 支持接入 SVN 仓库（可配置统一账号），用于历史资产或配置文件管理 | P0 |
| F-REPO-05 | 仓库列表展示仓库类型（GitLab/Gitea/SVN）、关联项目、最近同步时间、健康状态 | P0 |
| F-REPO-06 | 支持测试仓库连通性，失败时给出明确错误提示 | P0 |
| F-REPO-07 | 支持配置仓库 webhook，用于提交事件推送 | P1 |
| F-REPO-08 | Git 仓库支持分项目配置管理员账号或用户级 Token，用于拉取提交记录、创建 TAG 等操作 | P0 |

### 4. 凭证管理中心

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-CRED-01 | 凭证列表：展示凭证名称、类型（Token/账号密码）、所属用户、作用范围、过期时间、状态 | P0 |
| F-CRED-02 | 凭证新增：支持选择凭证类型（GitLab Token/Gitea Token/SVN/Jenkins/LDAP/AI Key 等）、认证模式（Token / 账号密码） | P0 |
| F-CRED-03 | 凭证编辑/删除：支持修改凭证内容、名称、过期时间，删除前校验是否被引用 | P0 |
| F-CRED-04 | 凭证作用范围设置：个人凭证、项目级凭证、系统全局凭证 | P0 |
| F-CRED-05 | 凭证内容脱敏展示：列表页不展示完整 Token/密码，仅显示前几位和后几位 | P0 |
| F-CRED-06 | 凭证使用记录：展示凭证最近使用时间、调用来源模块 | P1 |
| F-CRED-07 | 到期提醒：过期前给出视觉提醒或通知 | P2 |

### 5. 提交记录审查（Commit 规范督查）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-COMMIT-01 | 查询指定分支的提交记录列表，展示提交人、时间、哈希、原始日志 | P0 |
| F-COMMIT-02 | 按照 commit 规范自动校验：检查是否包含"变更类型""更新内容""配置项改动""关联性改动"等必填/可选项 | P0 |
| F-COMMIT-03 | 非法提交记录预警：不符合规范的提交高亮显示，支持标记为"待整改""已确认忽略" | P0 |
| F-COMMIT-04 | 支持 AI 辅助审查：对 commit 内容进行语义分析，识别是否包含配置变更、是否影响其他模块、是否遗漏关联项改动 | P1 |
| F-COMMIT-05 | 支持按提交人、时间范围、规范符合状态筛选提交记录 | P1 |
| F-COMMIT-06 | 审查结果导出：支持导出不合规提交清单（Excel/PDF） | P2 |

### 6. TAG 生成与发布

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-TAG-01 | 抓取 develop 分支从上一个 tag 到最新的所有提交记录 | P0 |
| F-TAG-02 | 支持合并、去重、编辑提交记录，生成发布说明 | P0 |
| F-TAG-03 | 按照发布规范模板生成发布文档，包含版本号、Git 哈希、变更类型、更新内容、配置项改动、关联性改动、测试验证、发布人等字段 | P0 |
| F-TAG-04 | 支持人工校验核对，核对通过后方可进入发布流程 | P0 |
| F-TAG-05 | 支持一键推 tag，正式 tag 只能从主分支发布，测试 tag 必须带有 test 标识 | P0 |
| F-TAG-06 | 正式发布与测试发布区分：测试版本不允许放入正式发布文件夹 | P0 |
| F-TAG-07 | 支持 AI 辅助生成发布说明：基于 commit 内容自动归纳更新摘要、风险提示、关联模块 | P1 |

### 7. Jenkins 自动打包发布

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-JENKINS-01 | 项目维度配置 Jenkins 任务：支持配置 Jenkins 地址、任务名称、凭证、构建参数 | P0 |
| F-JENKINS-02 | 发布流程中可触发 Jenkins 自动打包，实时展示构建状态（排队中/构建中/成功/失败） | P0 |
| F-JENKINS-03 | 构建成功后自动获取构建产物，支持关联到发布记录 | P0 |
| F-JENKINS-04 | 构建失败时展示日志摘要，支持跳转 Jenkins 查看完整日志 | P1 |
| F-JENKINS-05 | 支持 SVN/GitLab 联动打包：根据发布类型选择触发对应仓库的构建任务 | P0 |

### 8. 工作流审核管理

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-WORKFLOW-01 | 支持按项目配置审批流：可配置一级/多级审批人、审批节点、会签/或签模式 | P0 |
| F-WORKFLOW-02 | 发布申请提交后，按审批流自动流转，审批人收到待办通知 | P0 |
| F-WORKFLOW-03 | 审批人可查看发布详情、提交记录、构建结果，执行通过/驳回/转交操作 | P0 |
| F-WORKFLOW-04 | 每个审批节点记录审批意见、时间、操作人，全程留痕 | P0 |
| F-WORKFLOW-05 | 支持配置审批超时提醒、自动转交规则 | P1 |
| F-WORKFLOW-06 | 我的待办/已办：展示当前用户需要审批和已经审批的发布申请 | P0 |

### 9. 发布信息检索看板

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-DASHBOARD-01 | 发布看板总览：展示近 7/30 天发布次数、成功/失败比例、待审批数量 | P0 |
| F-DASHBOARD-02 | 发布记录列表：支持按项目、版本号、发布时间、发布人、状态筛选 | P0 |
| F-DASHBOARD-03 | 发布详情：展示发布说明、关联 commit、构建产物、审批记录、操作日志 | P0 |
| F-DASHBOARD-04 | 支持按模块/变更类型统计发布内容分布 | P1 |
| F-DASHBOARD-05 | 支持发布记录导出为 PDF/Word 发布单 | P2 |

### 10. AI 辅助优化

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-AI-01 | AI 辅助生成 commit 提交日志草稿，用户人工校正后提交 | P1 |
| F-AI-02 | AI 审查 commit 规范，给出修改建议 | P1 |
| F-AI-03 | AI 基于 commit 内容自动提取更新要点、风险提示、关联模块 | P1 |
| F-AI-04 | AI 辅助生成版本发布说明，支持人工二次编辑 | P1 |
| F-AI-05 | AI 识别高风险发布：如包含配置项改动、关联模块多、主分支外发布等场景自动提醒 | P2 |

### 11. 系统管理（超级管理员）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| F-ADMIN-01 | 用户管理：查看系统用户列表，手动同步域账号用户，调整用户角色 | P0 |
| F-ADMIN-02 | 角色权限管理：定义角色及其拥有的菜单/按钮权限 | P0 |
| F-ADMIN-03 | 系统参数配置：LDAP/AD 配置、Jenkins 全局配置、AI 服务配置、存储配置 | P0 |
| F-ADMIN-04 | 操作日志审计：查看用户关键操作日志，支持按时间、用户、操作类型筛选 | P0 |
| F-ADMIN-05 | 系统公告/消息模板配置 | P2 |

## 三、非功能性需求

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| NF-FE-01 | 前端采用响应式布局，兼容主流浏览器（Chrome/Edge/Firefox） | P0 |
| NF-FE-02 | 关键操作（提交、审批、发布）需二次确认，操作成功后给出反馈 | P0 |
| NF-FE-03 | 页面加载、提交请求需提供 loading 和骨架屏体验 | P1 |
| NF-FE-04 | 支持暗黑模式切换（可选） | P3 |
| NF-FE-05 | 错误边界处理，异常页面友好提示 | P1 |

## 四、页面清单

1. 登录页
2. 首页/发布看板
3. 项目管理（列表、新增/编辑、详情、成员、规则、外站绑定）
4. 凭证管理（列表、新增/编辑、作用范围、使用记录）
5. 仓库管理（列表、新增/编辑、vendor 选择、凭证选择、连通性测试）
6. 提交记录审查页
7. TAG 生成与发布页
8. Jenkins 构建任务页
9. 工作流审批（我的待办、我的已办、审批详情）
10. 发布记录/发布详情
11. 系统管理（用户、角色、参数、日志）
