方案 C · 双胶囊悬浮 推荐 5 触点

左胶囊（菜单 + 当前页）与右胶囊（消息 + 我的）悬浮分组，中央 + 与胶囊同高对齐、不凸起。左右手拇指各自覆盖一个胶囊，功能分区最符合直觉；悬浮感也贴合现有的玻璃拟态语言。
