# 已确认设计方向：A · 可展开树表

确认时间：2026-09-11

用户选择采用方向 A。正式实现沿用以下约束：

- 产品详情的发布版本按「软件仓库 → 发布版本」二级展示。
- 软件仓库作为可展开的一级分组行；发布版本作为二级数据行，并保持列对齐。
- 一级行展示仓库名称、仓库标识、当前版本、版本数量及最近发布时间；收起后仍能获得仓库概览。
- 搜索范围包含仓库名称、仓库标识、版本号和 Tag，搜索时自动展开命中的仓库。
- 桌面端使用树表；移动端使用仓库分组卡片，版本使用紧凑卡片，避免表格列被挤压。
- 结构组件必须可复用，发布页面只提供数据与列定义；后续打包看板可替换子行内容继续使用同一仓库树结构。
- 仓库详情是单仓库上下文，继续使用现有扁平版本列表，不重复增加仓库层级。
- 用户可见文案只使用产品、软件仓库、版本、Tag 等既有概念，不出现「组件」或「组件名称」。

对应设计稿：`direction-a-tree-table.html`。
