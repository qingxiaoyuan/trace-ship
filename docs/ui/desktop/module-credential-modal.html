类型驱动认证模式

GitLab / Gitea / GitHub / Gitee / AI 等纯 Token 凭证，自动锁定认证模式为 Token 并隐藏「认证模式」字段；SVN / LDAP 等可选 Token 或用户名密码。

密码模式渐进披露

选择「用户名密码」后以高度动画展开用户名输入；Token 字段标签随之切换为「密码」，编辑态占位提示「留空表示不修改」。

作用域条件联动

个人 / 全局无需关联项目；仅当作用域为「项目」时展开关联项目选择器，并设为必填。
