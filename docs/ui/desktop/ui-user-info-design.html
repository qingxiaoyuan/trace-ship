关键尺寸与对齐规范

触发器尺寸：高 40px（h-10），最小宽度 112px（min-w-28），内部姓氏色块 24×24px（h-6 w-6），圆角 8px（rounded-lg）。

文字层级：姓名使用 12px semibold（text-[12px] font-semibold），角色使用 10px regular（text-[10px] text-slate-500）；行高 leading-tight，两行间距 mt-1（4px）。

对齐方式：触发器与下拉菜单共用同一个 relative 父容器；下拉菜单使用 absolute right-0 top-full，保证右边缘与触发器右边缘对齐。

间距：触发器内部 gap 10px（gap-2.5）；文字区域行高 leading-tight，姓名与角色间距 4px（mt-1）；下拉箭头使用 ml-auto 自动右推。

配色：姓氏色块沿用原头像渐变 linear-gradient(135deg, #6366F1, #06B6D4)；边框使用 indigo-500 的 15% 透明度。

交互：Hover 时阴影增强、边框颜色加深；文字 hover 后变为 indigo-600；点击时轻微缩放 active:scale-[0.98]。

可直接复用的 HTML 片段

<div class="relative">
  <button type="button"
    class="group flex h-10 min-w-28 items-center gap-2.5 rounded-lg bg-white pl-2.5 pr-3
           shadow-card transition-all hover:shadow-cardHover
           active:scale-[0.98]"
    style="border: 1px solid rgba(99, 102, 241, 0.15);">

    <!-- 姓氏色块 -->
    <span class="flex h-6 w-6 shrink-0 items-center justify-center rounded-md
                 text-[12px] font-semibold text-white"
          style="background: linear-gradient(135deg, #6366F1, #06B6D4);">
      系
    </span>

    <!-- 姓名 + 角色 -->
    <span class="flex min-w-0 flex-col items-start leading-tight">
      <span class="max-w-24 truncate text-[12px] font-semibold text-slate-800">系统</span>
      <span class="mt-1 text-[10px] text-slate-500">管理员</span>
    </span>

    <!-- 下拉箭头 -->
    <svg class="ml-auto h-3 w-3 shrink-0 text-slate-400
                transition-transform group-hover:text-indigo-500
                group-data-[state=open]:rotate-180">...</svg>
  </button>

  <!-- 下拉菜单：右对齐 -->
  <div class="absolute right-0 top-full mt-2 w-[160px] rounded-xl
              bg-white py-1 shadow-dropdown"
       style="border: 1px solid rgba(99, 102, 241, 0.10);">
    ...
  </div>
</div>
