# 渲染验收

修改 Markdown、富文本、结构化正文的解析、编辑、保存或展示时，实施与审查均使用本标准。具体验收范围以关联 Issue 最新正文和评论为准；范围外功能在报告中注明。

涉及认证恢复、详情深链、异步日志或文件下载的改动，另按下方「交互验收」检查真实浏览器行为。

## 三项完成条件

| 验收层 | 完成条件 | 必要证据 |
| --- | --- | --- |
| 内容完整 | 原有字段及顺序、额外行列、表格外正文、空行、缩进和长文本尾部均保留；显示的业务内容与保存内容一致 | 实际输入样本、数据/页面断言；涉及编辑时包含保存后重新读取 |
| DOM 语义 | 应呈现为标题、强调、链接、换行、代码和表格的内容具有对应元素或可访问角色；续行仍属于原单元格 | 生产组件或真实页面的 DOM 断言，核对元素、单元格归属及链接目标 |
| 实际布局 | 桌面宽 1440px 和手机宽 375px 下内容可读，页面无意外横向溢出；宽表格可在自身容器横滚，主操作可见且可用 | 两种实际视口的浏览器观测、关键交互结果和截图；记录实际宽高 |

数据或 `textContent` 包含原文只证明内容存在。粗体应有 `strong`，链接应有 `a` 及正确 `href`，显式换行应有 `br`；表格应检查行列及内容归属。jsdom/SSR 语义测试不能证明浏览器排版，截图也不能证明长文本尾部完整或危险 URL 已过滤。

移动端导航、弹层、触控目标及底部留白同时遵守[移动端适配 ADR](../adr/0014-frontend-mobile-adaptation.md)。

## 样本与回归

1. **取得真实格式。** 从当前业务生成器输出或已有保存数据取得可复现样本，记录来源、生成步骤及对应版本；测试中可将脱敏后的输出固定为夹具。保留原有转义、物理续行和字段布局，核对其与当前生成器一致。
2. **覆盖组合边界。** 按下表挑选受本次修改影响的组合，为历史故障保留定点回归。每个不适用项注明原因。
3. **验证保存往返。** 有编辑入口时走读取、编辑、保存、重新读取及再次打开编辑器；比较字段、正文、缩进、换行和转义，确认没有重复转义、丢失内容或错列。

| 样本 | 应验证的行为 |
| --- | --- |
| 标准生成两列表格中的转义管道符与物理续行同时出现 | 管道显示为字面字符，续行留在同一值单元格，字段顺序不变 |
| 行首 `<br>` 后接强调、链接或缩进文本 | 换行存在，后续 Markdown 继续具有语义，缩进按该字段协议保留 |
| 额外字段、空行、长文本与混合正文/多列表格 | 首尾与表格外内容完整，额外行列不被标准模板截去 |
| 行内代码和围栏代码内的 `<br>`、HTML 或 Markdown 标记 | 示例保留字面内容，代码中的标签不成为实际元素 |
| 普通 HTTPS 链接与危险 URL、脚本及带事件属性的 HTML 同时出现 | 普通链接正常，危险 URL 不能成为可执行链接，未授权 HTML 不生成可执行元素 |

现有范例为[发布详情回归](../../frontend/src/pages/Release/Detail.test.tsx)与[Markdown 组件回归](../../frontend/src/pages/Release/components/ReleaseMarkdown.test.tsx)。复用现有覆盖；新增用例应锁定新行为或缺口。

## 浏览器取证

1. 使用真实页面和代表性数据，记录提交、页面路径、用户角色、浏览器及版本、操作系统、数据来源。隔离验收数据与生产数据，证据中移除凭证和个人信息。
2. 分别设置 1440px 与 375px 宽度。每次导航、刷新或切换视口后重新观测当前页面，确认实际 `window.innerWidth` / `innerHeight`、数据加载及布局完成，再截图。工具返回的设置参数不等于已确认的实际视口；旧截图或旧 DOM 观测不能作为新视口证据。
3. 阅读正文首尾及所有相关区域，核对 DOM 语义、字段归属和主操作；宽表格实际横向滚动并确认能到达末列。记录页面/容器宽度与滚动变化，以区分局部横滚和整页溢出。
4. 若涉及编辑，执行保存往返并重新观测；若涉及列表跳转，确认进入详情与返回后上下文符合规格。分别保存桌面和手机关键状态的截图。

浏览器视口模拟需标明；只有在真实手机上验证后才可称为真机验收。报告标明已测浏览器及尚未覆盖的环境。工具受阻或页面未加载的验收项保持待验证状态。

## 证据与结论

### 交互验收

复用[自动检查约定](pr-checks.md#真实浏览器冒烟)中的隔离冒烟入口与证据格式；本地与 CI 使用同一组样本。按变更范围确认：

- 详情从链接直接打开、持久会话冷启动及刷新后，路径和查询条件保持正确；失效会话显示真实登录状态。
- 长日志末尾确实可见，增量追加后可读；断言虚拟列表可见内容，不能仅以原文存在于数据中作为依据。
- 下载文件与来源原字节一致，ZIP 核对完整清单及内容；缺失、部分过期及请求失败均显示真实错误，不产生成功空文件。
- 记录上节要求的浏览器、提交、角色和实际视口；保留操作结果及下载校验，并将可访问的证据链接附在 Issue/PR，注明保留期限。

自动冒烟覆盖交互回归；布局仍按适用的桌面/手机范围人工观测。已确认不提供的手机功能标为不适用，不通过新增入口扩大范围。
