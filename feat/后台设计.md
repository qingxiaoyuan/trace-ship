# 后台设计文档（Python Django + DRF）

## 一、设计目标

为软件版本发布管理系统提供统一后端服务，支撑项目接入、代码仓库管理、提交规范审查、TAG 生成与发布、Jenkins 自动打包、工作流审批、发布看板等能力。

---

## 二、技术选型

| 层级 | 技术 | 版本建议 | 说明 |
|-----|------|---------|------|
| 开发语言 | Python | 3.11+ | 开发效率高，AI 生成代码质量好 |
| Web 框架 | Django | 5.x | 自带 ORM、Admin、认证、迁移 |
| API 框架 | Django REST Framework | 3.15+ | RESTful API 快速开发 |
| 数据库 | PostgreSQL | 16+ | 跨平台、JSON 字段支持好 |
| 缓存/会话 | Redis | 7+ | 缓存、分布式锁、Celery 消息代理 |
| 任务队列 | Celery + Redis | 5.x | 异步任务、定时任务 |
| 工作流 | 自研状态机 | - | 基于 LogicFlow 导出的 JSON 流程定义驱动 |
| 认证 | django-auth-ldap + JWT | - | 对接 LDAP/AD，本地应急管理员并存 |
| 外部集成 | python-gitlab / python-jenkins / ldap3 / subprocess(svn) | - | GitLab、Jenkins、LDAP、SVN |
| 容器化 | Docker + Docker Compose | - | 一键部署 |

## 五、核心模块设计

### 5.1 认证与权限

- LDAP 登录：`django-auth-ldap` 配置 LDAP 后端，首次登录自动创建本地用户。
- 本地应急账号：超级管理员可创建 `source=local` 用户。
- JWT：`djangorestframework-simplejwt` 提供 Token。
- 权限校验：
  - 超管：直接放行
  - 项目内权限：通过 `ProjectMember.role` 判断
  - 功能权限：Django 内置权限 + 自定义 permission 类

### 5.2 项目管理

- 项目 CRUD 仅超管或项目管理员可操作。
- 项目成员维护：项目管理员可添加/移除/修改角色。
- 项目停用后禁止新增发布。

### 5.3 仓库管理

- GitLab：使用 `python-gitlab` 操作仓库，`credential_value` 加密存储。
- SVN：调用系统 `svn` 命令行或 `pysvn` 获取日志与差异。
- 仓库连通性测试：尝试列出分支/GitLab project / SVN info。

### 5.4 提交记录审查

- 拉取 commit 后解析 `message`，按规范提取：
  - 变更类型（有/无配置项改动）
  - 更新内容（A/F 标记）
  - 配置项改动（INI 格式）
  - 关联性改动（各模块版本）
- 不合规项标记 `review_status=illegal`，并给出原因。
- AI 辅助：将 commit message 传给大模型，返回风险提示与补全建议。

### 5.5 TAG 生成与发布

- 版本号计算：读取上一个 tag，按项目配置的 `version_rule` 递增。
- 发布说明生成：聚合选中的 commit，按模板输出 JSON。
- 发布校验：
  - 正式版本只能从主分支发布
  - 测试版本必须带 test 前缀
  - 正式发布需满足发布周期规则
- 推 tag：通过 GitLab API 创建 tag。

### 5.6 Jenkins 集成

- 触发构建：调用 `python-jenkins` 的 `build_job`。
- 状态轮询：Celery 任务每 10 秒查询一次构建状态。
- 构建产物：构建成功后解析 Jenkins API 返回的 artifacts。
- 失败阻断：构建失败不允许继续发布流程。

### 5.7 工作流引擎（自研状态机）

#### 5.7.1 流程定义

前端使用 LogicFlow 绘制，后端保存 `graph_data` JSON。

#### 5.7.2 支持的节点类型

| 节点类型 | 说明 |
|---------|------|
| start-node | 开始节点 |
| approval-node | 审批节点，支持 serial/or/and 模式 |
| cc-node | 抄送节点 |
| condition-node | 条件分支 |
| end-node | 结束节点 |

#### 5.7.3 支持的审批动作

- approve：通过，沿 condition=approved 的边流转
- reject：驳回，沿 condition=rejected 的边流转
- transfer：转交给他人，不流转
- revoke：发起人撤销

#### 5.7.4 审批人解析

节点 `properties` 中定义：

```json
{
  "approverType": "user/role/leader/project_leader/initiator",
  "approverValue": ["user_id"],
  "mode": "serial/or/and"
}
```

#### 5.7.5 核心推进函数

```python
def submit_task(task_id, action, comment, operator):
    # 1. 完成当前任务
    # 2. 根据 action 找到出边
    # 3. 创建下一节点任务
    # 4. 更新实例 current_node_ids
    # 5. 到达 end-node 时标记 completed
    pass
```

#### 5.7.6 流程进度回显

返回 `graph_data` + `node_status` 映射，前端 LogicFlow 根据状态渲染节点颜色。

### 5.8 发布看板

- 统计接口聚合发布次数、成功率、待审批数。
- 发布记录支持多维度筛选。

### 5.9 AI 接入

- 统一封装 `ai/client.py`，支持切换不同模型。
- 应用场景：commit 日志生成、规范审查、发布说明生成、风险识别。
- 所有调用记录到 `ai_invoke_log`。

## 七、外部系统集成设计

### 7.1 LDAP/AD

- 库：`django-auth-ldap`
- 配置：`AUTH_LDAP_SERVER_URI`、`AUTH_LDAP_BIND_DN`、`AUTH_LDAP_USER_SEARCH`
- 首次登录同步：用户名、邮箱、部门、DN
- 本地账号并存：`source=local` 用户走 Django 认证

### 7.2 GitLab

- 库：`python-gitlab`
- 操作：list projects/branches/commits/tags、create tag、get diff
- 凭证：Personal Access Token，加密存储

### 7.3 SVN

- 方式：调用系统 `svn` 命令行 或 `pysvn`
- 操作：`svn log`、`svn diff`、`svn info`
- 凭证：用户名密码，加密存储

### 7.4 Jenkins

- 库：`python-jenkins`
- 操作：`build_job`、`get_build_info`、`get_build_console_output`
- 异步轮询：Celery 任务定时查询构建状态

### 7.5 AI 大模型

- 封装统一 HTTP 客户端
- 支持 Claude / OpenAI / 文心一言 / 通义千问等
- 配置项：`AI_PROVIDER`、`AI_API_KEY`、`AI_MODEL`、`AI_BASE_URL`
