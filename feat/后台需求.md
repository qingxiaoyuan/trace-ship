# 后台需求文档

## 一、系统定位

为前端提供统一 API 服务，负责项目/用户/权限/仓库/Jenkins/工作流/AI 等核心业务能力的数据处理与外部系统集成。保障多项目隔离、操作可追溯、权限可控、发布流程可审计。

---

## 二、技术选型建议

- 开发语言：Java / Node.js / Go（根据团队技术栈确定）
- 数据库：MySQL / PostgreSQL（主库）+ Redis（缓存/分布式锁）
- 消息队列：RabbitMQ / RocketMQ（异步事件，可选）
- 任务调度：XXL-JOB / Quartz（定时同步、超时提醒）
- AI 能力：对接大模型 API（Claude / 文心一言 / 通义千问等）

## 五、数据库核心表（建议）

- `sys_user`：系统用户
- `sys_role`、`sys_permission`、`sys_role_permission`、`sys_user_role`：RBAC 权限
- `sys_project`：项目信息
- `sys_project_member`：项目成员
- `sys_repo`：代码仓库配置
- `sys_workflow_definition`：审批流定义
- `sys_workflow_instance`、`sys_workflow_task`：审批实例与任务
- `release_record`：发布记录
- `release_commit`：发布关联提交
- `commit_review`：提交审查记录
- `jenkins_job`：Jenkins 任务配置
- `jenkins_build`：Jenkins 构建记录
- `sys_operation_log`：操作日志
- `sys_config`：系统参数
- `ai_invoke_log`：AI 调用日志

## 六、外部系统集成

| 系统 | 集成方式 | 用途 |
|-----|---------|-----|
| LDAP/AD | LDAP 协议 | 域账号认证与用户信息同步 |
| GitLab | GitLab API / Webhook | 仓库管理、提交记录、tag 操作 |
| SVN | SVN 命令行/SDK | 提交记录、差异提取 |
| Jenkins | Jenkins REST API | 触发构建、获取构建结果 |
| AI 大模型 | HTTP API | commit 辅助、审查辅助、发布说明生成 |
| 消息通知 | 邮件/企业微信/钉钉/飞书 | 审批通知、构建结果通知 |
